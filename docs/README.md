# Bellows documentation

The docs are in folders by what you want to do. Each folder has a short index that says what is in it and where to start.

| Folder | For | Pages |
| - | - | - |
| [use/](use/README.md) | Developers of apps, agents and scripts that call a Bellows | [Build on Bellows guide](use/guide.md), [API reference](use/api.md), [Operators](use/operators.md) |
| [run/](run/README.md) | Operators who run a Bellows | [Running a Bellows on your own server](run/self-hosted.md), [Sealed deployment guide](run/sealed-deployment.md), [Configuration reference](run/configuration.md), [Admin API and admin CLI](run/admin.md), [Migrating from Forge AI](run/migrate-from-forge-ai.md) |
| [verify/](verify/README.md) | Anyone who wants to check which build a Bellows runs, and what has been verified | [Attested identity](verify/attestation.md) |
| [how-it-works/](how-it-works/README.md) | Anyone who wants to know how Bellows works and what it hides | [Design](how-it-works/design.md), [Payments](how-it-works/payments.md), [Oblivious HTTP](how-it-works/ohttp.md), [Privacy](how-it-works/privacy.md), [Threat model](how-it-works/threat-model.md) |
| [contributing/](contributing/README.md) | Contributors | [What the tests check](contributing/tests.md), and [CONTRIBUTING.md](../CONTRIBUTING.md) at the root |
| [brand/](brand/README.md) | Anyone using the logo | The Bellows mark, icon and link preview |

New to Bellows? Read the [README](../README.md) first, then the [Build on Bellows guide](use/guide.md).

Some other folders carry their own README: [`relay/`](../relay/README.md) (the Oblivious HTTP relay) and [`site/`](../site/README.md) (the static site built from these docs).
