An open AI gateway, paid with eCash.

Bellows is an OpenAI-compatible AI gateway that takes Cashu eCash per request. It is for developers who want AI models in their apps and agents with no accounts, and for anyone who wants to run a gateway of their own.

Developers GitHub

  • Pay with eCash

    Pay each request with a Cashu token, or top up a balance and use its key like an API key.

    How payments work

  • Sealed and checkable

    On a sealed deployment the operator cannot read your prompts, and your app checks the build before it sends anything.
