Build on Bellows

The guide: verify an engine, pay with eCash, chat, stream and go through Oblivious HTTP, with examples in curl, JavaScript and Python.

Bellows is an OpenAI-compatible AI gateway that you pay per request with Cashu eCash. This guide shows how an app, an agent or a script uses a running Bellows: pick one, check which build it runs, list its models, pay, send chat requests, stream answers, go through Oblivious HTTP, handle errors and take your money back. The last part points operators at the pages for running their own.

Every path, header and field here is described in full in API reference. The examples were run against a local Bellows with local test mints; How these examples were checked lists what ran and what did not.

In this guide

  1. Pick an engineUse the reference instance, or start a local engine with test mints while you build.
  2. Check which build it runsRead the attested identity, and verify it with verifyBellows before you send anything.
  3. List modelsRead the models, prices, mints and units an engine offers.
  4. Pay for requestsOpen a balance with eCash or Lightning, or pay each request with a token in a header.
  5. Send a chat requestSend an OpenAI chat request with curl, JavaScript or any OpenAI client, and read what it cost.
  6. Stream an answerStream the answer, and read the event that settles the request at the end.
  7. Send through Oblivious HTTPSend each call through a relay with bellowsFetch, so who is asking is hidden from the operator when someone else runs the relay.
  8. Handle errorsThe error shape, and what to do about the codes an app meets most.
  9. Read the balance and take it backRead the balance, and withdraw what is left as an eCash token.
  10. Use the client libraryWhat the client library in client/ exports, and how to bring it into your app.
  11. Run your own engineWhere to go next to run an engine of your own.
  12. How these examples were checkedWhich examples in this guide were run, against what, and which were not.
