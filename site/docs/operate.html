Operating a Bellows

Run a Bellows on Tinfoil Containers, step by step, so that requests, answers, balances and keys stay sealed from its operator.

This page runs a Bellows on Tinfoil Containers, step by step, so that its operator cannot read the requests, the answers, the balances or the keys. What each party can still see is in Threat model.

NOT VERIFIED marks every step that needs real sealed hardware and has not been checked there one by one. Those steps follow Tinfoil's public documentation and the deploy kit in this repository. The release workflows have run on GitHub (4. Release), and the reference instance runs release 0.1.2 this way. Everything else here has been run locally. "Not verified on sealed hardware" at the end lists the open points.

In this guide

  1. The deploy kitThe files that make a sealed deployment, and the rules pnpm deploy:check enforces.
  2. What you needThe accounts, servers, keys and rate cards to have ready before you start.
  3. 1. Make your deploy repositoryCopy the repository, edit tinfoil-config.yml and check it.
  4. 2. Make the keys, offlineMake the volume key, the wallet secret and the admin token on an offline machine, and back them up.
  5. 3. Run your keyserverRun the keyserver that releases your secrets only to an approved build.
  6. 4. ReleaseBuild, pin, tag and measure a release, and propose it for builds.json.
  7. 5. Approve the release in your keyserverApprove the release in your keyserver and sign your operator announcement.
  8. 6. Create the volume and the instanceCreate the encrypted volume and the instance on Tinfoil.
  9. 7. Check itCheck the health, the attested identity, the models and the admin API.
  10. Onion serviceAdd a Tor onion service as a sidecar.
  11. Oblivious HTTP under loadHow the gateway bounds anonymous encapsulated requests, and how to tune it.
  12. UpdatingRoll a new release out to a running instance.
  13. Backups and recoveryWhat protects the money when there is no database export.
  14. Rehearse locallyRun the image the way Tinfoil runs it, on your own machine.
  15. Not verified on sealed hardwareThe steps that have not yet been checked on sealed hardware.
