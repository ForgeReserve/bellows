Run your own engine

Where to go next to run an engine of your own.

  • To try it on your machine, follow Pick an engine. The repository's README lists every setting.
  • To run one with Docker behind your own TLS proxy, see "Running a Bellows" in the README. In that setup the operator can read requests in memory and can read the database.
  • To run one its operator cannot read, deploy it on Tinfoil Containers with the deploy kit: Operator guide goes step by step, and marks every step that has not yet been run on sealed hardware. Threat model says what each party can still see.
