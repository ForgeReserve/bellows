Quickstart

Every engine speaks the same API. List its models, open a balance with eCash, and send an OpenAI chat request with the balance key. Opening a balance needs a small proof of work; the guide has the solver.

With curl

Against any Bellows. Replace $SOLUTION with a proof of work solution and $KEY with the key the topup returns.

B=https://bellows.island-bitcoin.containers.tinfoil.dev
curl -s $B/v1/models | jq '.data[].id'

# open a balance with eCash from one of its mints
curl -s $B/v1/wallet/topup \
  -H 'content-type: application/json' \
  -H "X-Bellows-Pow: $SOLUTION" \
  -d '{"token": "cashuB..."}'

curl -s $B/v1/chat/completions \
  -H "authorization: Bearer $KEY" \
  -H 'content-type: application/json' \
  -d '{"model": "MODEL_ID", "messages":
       [{"role": "user", "content": "Hello"}]}'

With any OpenAI client

The balance key is the API key.

from openai import OpenAI

client = OpenAI(
    base_url="https://bellows.island-bitcoin.containers.tinfoil.dev/v1",
    api_key="sk-forge-...",
)
reply = client.chat.completions.create(
    model="MODEL_ID",
    messages=[{"role": "user", "content": "Hello"}],
)
print(reply.choices[0].message.content)

Without a balance

Pay one request at a time: send it with no key, read the 402, and send it again with X-Cashu: cashuB... for the amount it asks. The unused value comes back as eCash change. Pay per request in the guide shows it end to end.
