Reference instance

Release 0.1.2 runs sealed on Tinfoil Containers at this address. It takes real eCash. Check its build before you send it anything.

https://bellows.island-bitcoin.containers.tinfoil.dev

What it answers

Its public routes are free to read:

B=https://bellows.island-bitcoin.containers.tinfoil.dev
curl -s $B/healthz                 # liveness and the BTC/USD rate in use
curl -s $B/v1/models | jq '{units, mints, ids: [.data[].id]}'
curl -s $B/ohttp-keys | tail -c +3 | base64     # its Oblivious HTTP key

The models, prices and mints it offers can change. Read them from /v1/models each time.

What it charges

It charges the suppliers' cost with no margin: BELLOWS_MARKUP is 1 in its measured tinfoil-config.yml, and its operator pays its hosting. An instance you run yourself marks the cost up by 1.25 unless you set another markup.

Its default unit is sat: a request that names no unit is asked in sats. Send X-Forge-Unit: usd to pay in cents.

To check its prices, compare pricing.usd_per_mtok in /v1/models with the supplier's cost, input_usd_per_mtok and output_usd_per_mtok in config/models.json at the release tag it runs. At markup 1 they are equal. Prices in the configuration reference says more.

What has run there

  • Releases 0.1.0, 0.1.1 and 0.1.2 were built and measured by the public release workflows, and each is listed in builds.json.
  • /healthz, /v1/models and /ohttp-keys answer.
  • A paid request, an Oblivious HTTP round trip and reading a balance back after a restart are covered by the test suite and local runs. They have not yet been run on sealed hardware.

Not verified on sealed hardware lists every step that has not been checked there.

Use it
